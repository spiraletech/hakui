# Runtime Body Profiles v0.1

HAKUI now owns one runtime body-profile controller. Male and female are presentation profiles on the same skeleton, movement, combat, ride, seat, interaction and world simulation.

- default: `male`
- startup override: `HAKUI_BODY_PROFILE=male|female`
- runtime toggle: `F6`
- canonical state key: `avatar.body_profile`

Mannequin Lab remains an isolated rig-science surface and resolves its male/female shell through the same immutable `BodyProfile` data.
